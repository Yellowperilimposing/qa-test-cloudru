# QA Test (cloud.ru)

## Установка Python

1. Установите Python на свой ПК.  
   Перейдите на страницу [https://www.python.org/downloads/](https://www.python.org/downloads/) и скачайте версию **Python 3.13.3**.

2. Запустите скачанный файл с расширением `.exe`.

3. В открывшемся окне внизу установите флажок **"Add python.exe to PATH"**, чтобы добавить путь к интерпретатору в переменные среды.

4. Нажмите **Install Now** — Python будет установлен на ваш компьютер.

5. Откройте PowerShell или CMD и выполните команду:

   ```bash
   python --version
   ```

   Убедитесь, что Python установлен — в терминале отобразится версия:

   ```
   Python 3.13.3
   ```

## Установка зависимостей

1. Установите плагин **pytest-playwright**:

   ```bash
   pip install pytest-playwright
   ```

2. Проверьте, что установка прошла успешно:

   ```bash
   pip show pytest-playwright
   ```

   В поле **Version** должна быть указана версия `0.7.0`.

3. Установите необходимые браузеры:

   ```bash
   playwright install
   ```

## Клонирование проекта

Склонируйте проект на локальную машину. Перейдите в папку с проектом через PowerShell или CMD.

## Запуск задач

### Задача «Алгоритмы»

Для запуска выполните команду:

```bash
python numbers.py
```

### Задача «Автоматизация тестирования»

Для запуска выполните команду:

```bash
python test_example.py
```

После запуска откроется браузер Chrome и начнётся выполнение теста.
